# Code review, maintainer lens (Kim)

Verdict: Core math is sound, tested and easy to own, but the page script has a few real input bugs (minus button, absurd values, silent copy failure) and nothing runs the tests before deploy. Must-fix count: 3.

Known template leftovers (template README, new-tool.sh, tracked screenshots, duplicate legal links, build-date "Last updated", British spelling) are on the fixer's list and not repeated below.

Checked: `npm test` passes (20 tests). I also ran 30+ edge inputs through `computeFeed`, `peakTime`, `formatHours` and `gramsToCups` by hand in node.
